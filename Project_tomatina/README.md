# LeafAI — Tomato Disease Detector 🍃🍅

LeafAI is a high-performance, AI-powered diagnostic tool for tomato plants. It uses a custom-trained TensorFlow model to identify common leaf diseases and provides real-time, AI-generated treatment advisories using OpenRouter.

## ✨ Features
- **AI Classification**: Real-time detection of 10+ tomato leaf conditions.
- **Visual Confidence**: Glass-morphism dashboard with top-3 prediction breakdown.
- **Smart Advisories**: Treatment "gists" generated by Llama 3.2 / Gemini via OpenRouter.
- **Production-Ready**: Modular backend architecture for high performance and scalability.

## 🚀 Quick Start (Local)

### 1. Prerequisites
- Python 3.11+
- [OpenRouter API Key](https://openrouter.ai/) (optional, has fallback)

### 2. Setup
```bash
# Clone the repository
git clone https://github.com/your-repo/leafai.git
cd Project_tomatina

# Install dependencies (in a virtual env)
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
```

### 3. Run
```bash
export OPENROUTER_API_KEY=your_key_here
cd backend
PYTHONPATH=. python3 app.py
```
Access the app at: **http://127.0.0.1:5050**

## 🧩 Architecture

- **`frontend/`**: Vanilla HTML5/CSS3/JS with glass-morphism aesthetic.
- **`backend/`**: Modular Flask application.
  - `core/`: Model inference and AI logic.
  - `api/`: Endpoint definitions.
  - `models/`: Pre-trained weights and class mappings.
